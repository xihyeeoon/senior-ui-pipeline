# kb/ — 사후 대조용 규칙 모음

`senior_kb.csv` 는 고령자 관련 설계 규칙 46개다 (`relation` 열에 규칙 id:
SDF-\* 41개, KS-\* 5개).

**생성에는 쓰지 않는다.** 용도는 **재구성본 사후 대조** 하나다 — 만들어진 설계가
결과적으로 어떤 규칙에 해당하는지 나중에 확인하는 것. 재구성본을 만들 때 이 파일을
모델에 주지 않았고, 앞으로도 주지 않는다. 이것이 `restructure-changelog.md` 가
답하는 질문을 "규칙을 어떻게 적용했나" 가 아니라 "규칙을 주지 않아도 결과적으로
지켜진 것은 무엇이고, 어느 규칙에도 해당하지 않는 변경은 무엇인가" 로 만든다.

대조 결과는 뷰어의 **변경 추적** 탭에서 본다. 표가 실제로 인용하는 규칙과
`docs/restructure-changelog.md` 가 충족됐다고 적는 규칙이 다르므로 (26 vs 33)
나눠서 표시한다.

경위: 이 파일은 DesignRepair 에 물려 돌릴 시스템 수준 KB 로 만든 것이다. 그
갈래는 2026-09-30 에 연구에서 뺐고(관련 코드와 자료는 커밋 `66186fe` 까지의
히스토리에 있다), KB 만 사후 대조용으로 남겼다.
