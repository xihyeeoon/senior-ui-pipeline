# 공과금 원본 — 캡처만 보고는 알 수 없는 것

`inputs/original_bill.html` 과 `flows/original_bill.json` 을 만들며, 캡처
(`senior-ui-dummy-app/docs/screenshots/` 의 `01_메인` · `02_메뉴` · `03_공과금납부`)만
보고는 정할 수 없어 **더미앱 코드**나 **판단**으로 채운 정보의 목록이다. 이 HTML 은
나중에 만들 앞단(스크린샷 → HTML)의 정답지로도 쓰므로, 앞단이 이 항목들을 사람에게
물어야 한다 (`docs/input-contract.md` 의 (나)).

출처의 "더미앱" 은 `senior-ui-dummy-app` 커밋 `00834ca` 의 파일이다. 줄 번호 L 은
`inputs/original_bill.html` 기준이다.
